# 🎛️ Audition x FL Studio v8.0 PRO

**Audition x FL Studio v8.0 PRO** — это мощный настольный аудиоредактор и студия быстрой обработки звука для Windows, объединяющая удобство работы с волновой формой и креативные эффекты в одном окне.

## ✨ Основные возможности

* **Работа с треками и пакетами:** загрузка одиночных аудиофайлов (MP3 / WAV), пакетная обработка альбомов и удобное A/B-сравнение с референс-треком.
* **Умный анализ аудио:** автоматическое определение **BPM**, тональности (**KEY**), громкости (**LUFS**) и пиковых значений (**PEAK**).
* **Секция Gross Beat и MPC Pads:** мгновенные эффекты замедления (*1/2 Speed*), остановки ленты (*Tape Stop*), *Stutter*, встроенный метроном, сэмпл-пэды (*808 Drop, Clap, Horn*) и сайдчейн-модули (A/B/C/D).
* **Пресеты и изоляция (Solo):** готовые цепочки обработки (*Фолк, Вокал, Бас, OTT*), слоты памяти A/B/C и быстрое прослушивание отдельных частот или стемов (*Микс, Вокал, Минус, Бас, Верха*).
* **10-полосный графический эквалайзер (Graphic EQ):** точная ручная настройка частот плюс готовые кривые (*Улыбка, Вокал, Винил, Воздух*).
* **Аппаратное ускорение:** поддержка переключения обработки между **GPU** и **CPU** с мониторингом нагрузки в реальном времени.
* **Оформление релиза:** заполнение метаданных (Исполнитель, Название, Альбом) и добавление обложки (`Cover.jpg`).

## 📥 Как скачать и запустить (Windows)

1. Перейдите в раздел **[Releases](https://github.com)** (справа на этой странице).
2. Скачайте архив **`AuditionStudio-win32-x64.zip`**.
3. Распакуйте архив в любую удобную папку на компьютере.
4. Запустите файл **`AuditionStudio.exe`** (установка не требуется).
